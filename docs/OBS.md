## projection mapping tools

### [corner-pin](https://obsproject.com/forum/resources/corner-pin.1474/)

> based on https://github.com/Oncorporation/obs-shaderfilter/blob/master/data/examples/corner_pin.shader

skewing the source by defining x/y offsets for each corner

### [obs-3d-effect](https://github.com/exeldro/obs-3d-effect)

skewing the source by defining rotations, maybe faster than 4 corners?

[obs forum post](https://obsproject.com/forum/resources/3d-effect.1692/)

### [obs-shaderfilter](https://github.com/exeldro/obs-shaderfilter)

for loading custom GLSL shaders, worst case if you need something special special

[shader examples](https://github.com/exeldro/obs-shaderfilter/tree/master/data/examples)
